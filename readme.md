# ☕☕☕ AstroBrew - Café Temático

**Propósito de la página**
AstroBrew es una cafeteria online temática de café con sabores inspirados en el espacio exterior. El sitio muestra productos (mezclas estelares), reseñas de clientes (astronautas ficticios) y formulario de contacto funcional. Fue creada como proyecto educativo para demostrar el uso de HTML semántico, CSS (Flexbox, Grid, Media Queries) e integracion con Formspree.

## Tecnologías utilizada

- HTML semántico (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- CSS3 externo con: 
    - **Flexbox** -> usado en la seccion de productos para que las cards se organicen automaticamente en filas adaptables.
    - **CSS Grid** -> usado en la seccion de reseñas para crear una cuadricula que cambia de columnas segun el ancho de la pantalla.
    - **Media Queries** -> en la seccion de contacto para que el formulario y la informacion se apilen en moviles.
    - **Formspree** -> El formulario envía datos al endpoint `https://formspree.io/f/mqkrygvl`.
